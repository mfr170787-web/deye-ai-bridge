# Smart Home Dashboard 0.1.6

Separat Home Assistant-dashboard med flytbare widgets til Deye-energi, priser,
solprognose, Tuya, Philips Hue, temperatur, vejr og øvrige HA-enheder.

- Layout gemmes lokalt på Home Assistant.
- Lys, kontakter og input booleans kan betjenes.
- Understøttede lys får lysstyrke og farve.
- Energidata læses fra Deye AI Bridge; dashboardet ændrer ikke energistyringen.
